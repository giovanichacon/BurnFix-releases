# BurnFix releases

Windows installers for BurnFix and the in-app update feed. This repository holds release assets only; the source code is private.

- Download: see [Releases](https://github.com/giovanichacon/BurnFix-releases/releases).
- Update feed used by the app: `https://github.com/giovanichacon/BurnFix-releases/releases/latest/download/latest.json`

The installer is not code-signed yet, so Windows SmartScreen may warn: choose "More info" and then "Run anyway".
